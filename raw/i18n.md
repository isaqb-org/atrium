# Internationalisation (i18n)

Status: collection, 2026-11-26. Objective: multilingual platform
(German and English at launch, Spanish and French within 6 months).

atrium needs an i18n concept before launch, even though only German and
English are needed then. It must allow more languages later without
rework: which content is translated, by whom, the English fallback per
field, and language-aware addresses.

## Provider profile languages

- The profile description is required in German and in English.
- More languages (Spanish, French, later others) are optional.
- A missing optional language falls back to English.

## Language switcher (placeholder)

- Every page offers a language switcher with the site languages.
- Switching keeps the visitor on the same page, in the other language.
