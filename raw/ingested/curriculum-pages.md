# Requirement: curriculum pages

Objective: clear path to certification. Priority: should (proposal).

Each curriculum gets a public page of its own, next to the module page.

| | Module page | Curriculum page |
|---|---|---|
| About | The Foundation Level or one Advanced Level module | One curriculum version, the document |
| Version | Independent of a curriculum version | Exactly one version |
| Content | Description, learning goals, credit points, number of upcoming training dates, link into the training finder; sometimes an excerpt of the curriculum | Title, version, release date, languages, download, what changed since the previous version |
| Links | To the latest and, if any, the upcoming curriculum | To its module page, and to the previous and next version |

**Acceptance criteria.**
- Given a module page, then it links to the latest curriculum and, if one
  is announced, to the upcoming one.
- Given a curriculum page, then it states its version and release date and
  offers the curriculum as a download in each published language.
- Given an older curriculum version, then its page says that a newer version
  exists and links to it.
- Given the site search, then curriculum pages appear in the category
  "Curriculum" and module pages in the category "Module".

Open: whether older versions keep a page or only the latest and upcoming
ones; whether the curriculum's full text becomes searchable.

Origin: human, during the site search capture, 2026-11-25.
