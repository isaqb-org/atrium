# Story: search all public content

Parent: site search. Priority: must.

**As** a visitor **I want** one search over all public content, **so that**
I need not know in which section something is.

**Acceptance criteria.**
- Given one item of each category (see "categorised results"), when I
  search for its title, then each one is found.
