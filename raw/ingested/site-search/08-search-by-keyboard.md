# Story: use the search by keyboard

Parent: site search. Priority: must.

**As** a visitor **I want** to open and use the search without a mouse,
**so that** I am fast and can search without a pointing device.

**Acceptance criteria.**
- Given any page, when I press the keyboard shortcut, then the focus is in
  the search field.
- Given the popup is open, when I press ↑/↓, Enter or Esc, then I select a
  result, open it, or close the popup.
- Given the results page, when I use only the keyboard, then I can reach
  every result and every category choice.
