# Objective: excellent usability

Parent: vision.

- **Purpose.** Every audience does its core tasks on atrium fast and without
  help.
- **Advantage.** Fewer drop-outs, fewer questions to the iSAQB office.
- **Metric.** System Usability Scale (SUS) score from test persons of every
  audience after a usability test of the core tasks.
- **Target.** SUS ≥ 80 on average.
- **Horizon.** At launch.

## Core tasks

| Audience | Core task |
|---|---|
| Certification prospect | Understand the path to certification |
| Certification prospect | Choose a suitable module |
| Certification prospect | Find an accredited training |
| Everyone | Look up a term |

Sub-goals for the two most important tasks: fast training date search,
clear path to certification.

## Open questions

- Alumni, members and companies have no core task yet.
- Maintaining the provider profile is no core task for now: DIWAN may take it
  over (not decided).
- Measure a baseline on today's site (success rate and time per core task) to
  set the sub-goals' targets. Who, when and on what budget is open.
