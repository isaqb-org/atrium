# Objective: technical excellence as a role model

Parent: vision.

- **Purpose.** atrium is a role model for sound architecture, implementation,
  maintenance and operation, and others can see how it is built.
- **Advantage.** iSAQB is an architecture organisation. Its own platform
  shows credibly what it teaches and makes the association's quality visible.
- **Metric.**
  1. Measured quality of the running site: Lighthouse (performance,
     accessibility, best practices, SEO) and axe checks.
  2. Openness: source code, arc42 documentation and decision records are
     public, built with open-source tools only.
- **Target.**
  1. Lighthouse ≥ 95 in each of the four categories on every page type.
     0 axe violations (WCAG 2.2 AA). Both checked automatically in every
     build.
  2. Source code, arc42 documentation and decision records public. No
     licence costs for tools.
- **Horizon.** At launch, then continuously.

## Open questions

- Security, modularity, extensibility and flexibility are not yet measured.
  Each needs a quality requirement with a measurable scenario.
- Maintainable by volunteers (from the cost objective) needs a quality
  requirement too, e.g. "a volunteer updates all dependencies in under two
  hours".
