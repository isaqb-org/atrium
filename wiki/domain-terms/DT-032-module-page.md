# module page

**Definition.** The public [[DT-027-atrium|atrium]] page for the [[DT-008-foundation-level|Foundation Level]] or one [[DT-011-advanced-level-module|Advanced Level module]]: description, learning goals, curriculum download, credit points, number of upcoming training dates and a link into the [[DT-028-training-finder|training finder]].

**In context.** The next step after choosing a module and before searching for a date. The search finds modules by title, short description and keywords, not by the curriculum's full text.

**Distinguish from.** [[DT-012-curriculum|Curriculum]]: the iSAQB document, which the module page offers as a download. [[DT-030-provider-page|Provider page]]: the page of a provider, not of a module.
