# Fairness towards providers and trainers

## Objective   > follows [[PAM]], [[SMART]] (target and horizon set)

- **Purpose.** atrium treats all accredited [[DT-016-training-provider|training providers]] and all [[DT-017-trainer|trainers]] alike. None is preferred in presentation, order or visibility.
- **Advantage.** Providers and trainers are partners, not advertising customers. A fixed order silently prefers whoever comes first, without anyone having decided that. The neutral association rules this out.
- **Metric.** Share of top-k positions, see `metric:`, `baseline:`, `target:`, `horizon:`.

**Principles.**
1. **Equal chance of visibility.** Where many providers or trainers appear side by side and not all fit, each has the same chance of a prominent position.
2. **Equal presentation.** Same area, same design, same display time.
3. **No ordering by attributes in the logo marquee**, not even alphabetical. Alphabetical provider lists, for example filter lists, are allowed.
4. **No highlighting.** No paid placements, no "featured" partners.
5. **No personalisation.** No order or highlighting by visitor attributes the visitor did not choose (page language, location, behaviour, role). Filters and sorting the visitor sets are allowed.

**Scope.** Displays without search intent: first the start-page [[DT-037-partner-logo-marquee|partner logo marquee]], and trainers once atrium shows them on its own, for example in a trainer directory. Not the [[DT-028-training-finder|training finder]]: its results stay sorted by start date. On equal start dates, the order is random but stable per day, so a shared link shows the same order that day and no provider gets a permanent edge.

Set by the [[STK-011-executive-board|executive board]].
